Running on the graph
He works harder going up, runs faster going down, and slips if it gets too steep.

Middle-school exploration: increasing, decreasing, flat, steep, corners, separate points. Only supported operations are +, −, ×, ÷, powers, parentheses, sin, cos, tan, sqrt, abs, floor and log. Trigonometry uses radians. Character art is an early articulated prototype based on the approved illustrated model.
